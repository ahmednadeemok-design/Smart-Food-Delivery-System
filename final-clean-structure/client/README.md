# Smart Food Delivery Client

React + Vite frontend for Smart Food Delivery System FYP.

## Run

```bash
cd client
npm install
copy .env.example .env
npm run dev
```

Backend must be running on:

```txt
http://localhost:5000
```

Default frontend URL:

```txt
http://localhost:5173
```

## Main Modules

- Authentication
- Restaurant list
- Menu and cart
- Checkout
- Order tracking with OTP verification
- Complaint resolver UI
- Subscription screen
- AI/health dashboard
