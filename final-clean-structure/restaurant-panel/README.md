# SmartFood Restaurant Panel

Restaurant dashboard for Smart Food Delivery System FYP.

## Run

```bash
cd restaurant-panel
npm install
copy .env.example .env
npm run dev
```

Runs on `http://localhost:5175`.

## Modules

- Restaurant owner login/register
- Dashboard analytics
- Order management
- Menu management
- Kitchen load indicator
- Order accuracy reports
- Quality audit / taste guarantee
