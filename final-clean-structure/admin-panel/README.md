# SmartFood Admin Panel

Admin dashboard for Smart Food Delivery System FYP.

## Run

```bash
cd admin-panel
npm install
copy .env.example .env
npm run dev
```

Runs on `http://localhost:5176`.

## Modules

- Admin login/register
- User management
- Rider management
- Restaurant management
- Complaint resolution
- Refund decision UI
- Trust score dashboard
- Platform analytics
